# COVID-19 Data Analysis

## Research Question
What is the global distribution of confirmed COVID-19 cases as of April 2020, and how do confirmed and recovered cases compare across different countries?

## Dataset Source
- Source: COVID-19 small dataset (publicly available)
- Time period: Data up to April 29, 2020
- Usage rights: Free for educational and academic purposes

## Methods and Tools
- Programming Language: Python
- Libraries: pandas, numpy, matplotlib, seaborn
- Analysis Type: Exploratory Data Analysis (EDA)

## Key Findings
1. The US had the highest number of confirmed COVID-19 cases as of April 2020, followed by Spain and Italy.
2. There is a positive correlation between confirmed cases and recovered cases across countries, though recovery rates vary significantly.

## Limitations
This analysis is based on a small simplified dataset and does not include demographic factors, testing rates, or healthcare system capacity, which are important for a complete understanding of the pandemic.
